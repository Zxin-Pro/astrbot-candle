紧急下线

      
停掉沙盒里 NapCat 与 AstrBot 的进程，收起常驻通知，并结束整个应用进程。登录状态、配置、AstrBot 数据都保留；下次打开应用不会自动拉起沙盒，要回到这张卡点启动。

后台守护

      
Android 在内存紧张时会冻结甚至杀掉后台应用，沙盒里的 NapCat 与 AstrBot 就会「进程还在、但完全没有反应」。开启下面的常驻守护后，本应用会保留一条常驻通知以维持前台优先级，每分钟自检一次沙盒，掉线就自动拉起；另外还有一条两分钟一次的闹钟心跳，即使整个应用被系统冻住，也会被叫醒并把沙盒兜回来。

      
如果挂后台一阵子还是掉线，多半是厂商省电策略：到下面「省电策略」里点「去设置」，把本应用设为「不限制 / 允许后台高耗电」，并打开「自启动」（vivo：i管家 → 应用管理 → 自启动；设置 → 电池 → 后台耗电管理 → 允许后台高耗电）。

省电策略

      
手机厂商的省电策略会把后台应用「冻结」：通知还在，沙盒却不再收消息。这里按机型跳到对应的设置页，把本应用设为「不限制」。小米/红米还要在最近任务里把本应用「锁定」；vivo / iQOO 要同时打开「自启动」与「允许后台高耗电」；华为/荣耀在「应用启动管理」里关掉自动管理。

隐私政策

    

      
AstrBot烛版（包名 zhuxin.astrbot，1.2.1 及更早为 com.termux）是一个本地运行环境管理器。我们把"收集什么、为什么收集、存在哪里、怎么删除"逐条写清楚，请在使用前完整阅读。

      
一、我们不收集个人信息

      
    
        
  • 本软件没有账号体系，不要求手机号、邮箱、实名信息，也不需要你注册登录。
    • 
        
  • 不做用户画像、个性化广告，不集成任何第三方统计或广告 SDK。匿名统计默认关闭，只有你手动开启后才会按第二节的字段发送。
    • 
        
  • QQ 登录凭据（含扫码登录产生的票据）、聊天记录、机器人配置全部只保存在本机应用私有目录，我们无法访问。
    • 
      

      
二、会上传的两类数据（都由你主动开启或提交）

      
    
        
  • 错误日志（手动提交）：只有你本人点击「上传错误日志」时，软件才会把本机的诊断日志（启动脚本输出、进程状态、系统与设备型号、崩溃堆栈）打包上传到我们的日志服务器。上传前会自动抹掉 QQ 号、群号、手机号、邮箱、令牌与二维码链接。目的只有一个：定位你反馈的故障。内容不含聊天记录、好友列表、账号密码、二维码图片。
