后台守护

      
Android 在内存紧张时会冻结甚至杀掉后台应用，沙盒里的 NapCat 与 AstrBot 就会「进程还在、但完全没有反应」。开启下面的常驻守护后，本应用会保留一条常驻通知以维持前台优先级，并每分钟自检一次沙盒，掉线就自动拉起。

终端

      
需要手动执行命令时可切到 Termux 终端。常用：qqbot-start / qqbot-stop / qqbot-status / qqbot-shell。

      

        
      

    

  


  

    

      
    


    

      
组件重装

      
重装会先停掉对应容器、删掉已安装的文件再重新下载安装，耗时几分钟，期间那个容器不可用。端口与登录数据保留。进度见日志页「其它日志文件」里的 reinstall.log。

      

        
        
      

    


    

      
端口设置

      
留空表示自动分配。改完端口请点下面的「保存并重启服务」让容器用新端口重新启动。

      
AstrBot 控制台

      

      

        
        
      

      
端口留空＝自动分配。WebUI 与 OneBot 端口必须同机唯一；改动后需要重新生成对接配置，点「保存并重启服务」会连同 AstrBot 平台配置一起重建。

    


    

      
下载代理

      
直连 GitHub / 腾讯下载慢或失败时，可以在这里填一个代理。留空表示直连。支持 http://、https://、socks5://，例如 http://127.0.0.1:7890。保存后，重新部署、重装组件、安装依赖都会走这个代理。
